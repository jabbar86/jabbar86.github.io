# Jabbar Memon — Portfolio

Static responsive portfolio using HTML, CSS and vanilla JavaScript. No build step, framework, or paid hosting required.

## Publish at https://jabbar86.github.io

1. Sign in to GitHub as `jabbar86`.
2. Create a **public** repository named exactly `jabbar86.github.io`.
3. Upload the contents of this project folder to the repository root (`index.html`, `styles.css`, `script.js`, `README.md`, and `assets/`).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for deployment, then open https://jabbar86.github.io.

## Résumé PDF
The Download résumé link expects `assets/Jabbar_Memon_Resume.pdf`. Add your final PDF at that path before publishing. If you do not add it, remove the Download résumé button from `index.html`.

## Customize
Edit `index.html` for content and `styles.css` for visual design. Review role dates, metrics, and descriptions before making the site public. Do not publish confidential customer or internal architecture information.
